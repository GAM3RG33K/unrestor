How it works

One long night. Three moments.

Unrestor holds your Mac awake only while something is asking for it, then lets go on its own.

11:42PM

Start it

Run your command through unrestor run, or flip the switch in the menu bar. That is a request to stay awake, nothing more.

12:00AM

Close the lid

A small background service stops the Mac from sleeping, with or without a charger. The process keeps running.

3:07AM

It lets go

The command exits, the hold is released, and your Mac sleeps. A low battery or a hot Mac ends it sooner.

Commands

Any tool you can start from a terminal.

Everything works without the menu-bar app. Each command stays in the foreground until it is done.

$ unrestor run -- npm test

Run

Awake exactly as long as the command runs. Its exit code passes through.

$ unrestor run --for 2h -- claude

Cap it

Add a time limit so a stuck job cannot keep the Mac up all night.

$ unrestor watch 4821

Watch a process

Already running something? Hold the Mac awake until that process ends.

$ unrestor hold --for 90m

Plain keep-awake

No command needed: stay awake until the timer ends or you press Ctrl-C. The menu bar has the same switch.

Safety

Built to let go.

Keeping a laptop awake with the lid shut is a bad idea if it never stops. Unrestor makes stopping the default. Read exactly what the service can do.

01

Released on every exit

A hold belongs to the process, timer, or switch that asked. Quit the app, crash, or lose the service and it is released.

02

Crash-safe restore

Your original sleep setting is recorded first and restored at the next launch, even after a reboot.

03

Limits always win

A battery floor you choose, a heat limit, and a power-only mode override any request.

04

A tiny privileged surface

The root service runs one fixed system command. It never runs yours, only your own user can talk to it, and it enforces the limits itself, so no program can switch them off.

Install

Three ways in. One extra step.

Unrestor is free and not notarized by Apple, which would need a paid account. It is built in the open on GitHub, so you can read the code and the build. macOS asks you to approve it once.

Homebrew

$ brew install --cask GAM3RG33K/tap/unrestor

Skips the macOS warning and puts unrestor on your PATH.

Download the DMG

→ Unrestor.dmg → Applications

On first open choose System Settings → Privacy & Security → Open Anyway.

Build from source

$ scripts/make-app.sh

Needs Xcode's command-line tools. Builds the same app and DMG on your Mac.

Then, once: install the background service

$ sudo unrestor install

Or open the app and choose Install Background Service…; macOS asks for your password. This is what lets the Mac stay awake with the lid closed. Remove it any time with sudo unrestor uninstall.

Stuck? Run unrestor help for the full guide, or unrestor status to see why the Mac is or is not staying awake. More in the troubleshooting guide.
